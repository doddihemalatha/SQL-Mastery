# Data and Information

## 1. What is Data?

**Data is a collection of raw facts and figures that are not organized or processed. By itself, data does not provide meaningful context and can be used as input for further processing.**

### Examples of Data

* Name
* Age
* Roll number
* Marks
* Phone number
* Date

### Example

```text
92
85
78
```

These are raw values. Without context, we do not know what they represent or whom they belong to.

---

## 2. What is Information?

**Information is processed and organized data that provides meaningful context and helps us understand something or make decisions.**

### Example

 Student       Marks 
 Hema          92 
 Ravi          85 
 Priya         78 

Now we can understand which marks belong to which student.

From this data, we can derive meaningful information:

> Hema scored the highest marks.

---

## 3. Data vs Information
 Data                             Information
 
 Raw facts and figures               Processed and organized data               
 May not have meaningful context     Provides meaningful context                
 Used as input for processing        Helps in understanding and decision-making 
 Example: `92, 85, 78`               Example: `Hema scored the highest marks`    

---

## 4. Real-Life Example

### Data

```text
Attendance = 68%
```

Without additional context, we may not know whose attendance it is or what it represents.

### Information

```text
The student's attendance is below 75%.
```
This provides meaningful context and can help in making a decision about the student's eligibility.

---

## 5. Key Concept

```text
Raw Data
   ↓
Processing + Organization + Context
   ↓
Meaningful Information
```

---

## 6. Key Takeaway

**Data is the raw input, while information is meaningful data obtained after processing and organization.**
